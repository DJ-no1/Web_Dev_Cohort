# ⚡ 30-Second Quick Start Guide

## 🚀 Start in 3 Commands

```bash
# Terminal 1: Start MongoDB
npm run db:up

# Terminal 2: Start Server
npm run dev

# Browser: Open
http://localhost:4000
```

## 🎬 Test in 30 Seconds

1. Click **Register**
2. Create account (skip email verification in dev)
3. Login with your credentials
4. Click **Book Now** on any show
5. Select 3 seats (click to toggle)
6. Confirm booking
7. View in **My Bookings** ✅

**Done!** 🎉
