# 🛍️ Instagram Store DB (Short README)

Simple database design for a thrift + handmade Instagram store.

## 📦 Covers

* Customers 👤
* Products & Variants 👕
* Orders 🛒
* Payments 💳
* Shipping 🚚
* Conversations (DMs) 💬
* Reviews ⭐

## ✨ Features

* Waitlist for out-of-stock items ⏳
* Business expense tracking 💸
* Product customization support 🎨
* Multi-variant products (size, color) 👕
* Order & payment tracking 📊

## 🔁 Flow

Customer → Chat → Order → Payment → Delivery → Review

## 🎯 Goal

Turn manual DM-based selling into a **structured, scalable system**.
