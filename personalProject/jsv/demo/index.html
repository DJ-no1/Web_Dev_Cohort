📖 How to Read This Visualizer

Call Stack — Where function calls live. Push when called, pop when returned.
Task Queue — setTimeout/setInterval callbacks wait here. Runs after Microtasks.
Microtask Queue — Promise.then() callbacks. Higher priority — runs before Task Queue!
Console — Output from console.log() calls.

💡 The Event Loop rule: When the Call Stack is empty → drain Microtask Queue completely → pick ONE item from Task Queue → repeat.
