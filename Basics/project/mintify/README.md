# Mintify Clone

A responsive landing page for Mintlify, an intelligent knowledge platform designed to help teams create and maintain world-class documentation.

## Project Overview

This project is a clone of the Mintlify marketing website, showcasing the key features and value proposition of an AI-powered documentation platform built for both humans and AI.

## Project Structure

```
mintify/
├── index.html          # Main HTML file with page structure
├── style.css           # Styling and layout
├── README.md           # Project documentation (this file)
└── assets/             # Images, videos, and media files
    ├── mintify.png     # Logo
    ├── bg-light.png    # Background image
    ├── hero.image.png  # Hero section image
    ├── feature-1.mp4   # Feature video 1
    ├── feature-2.mp4   # Feature video 2
    ├── feature-3.mp4   # Feature video 3
    └── [company logos] # Partner/customer logos
```

## Features

- **Responsive Navigation** - Top navbar with links to Resources, Documentation, Customers, Blog, and Pricing
- **Hero Section** - Eye-catching headline and value proposition
- **Modern Design** - Clean, professional layout with custom styling
- **Brand Assets** - Logo, background images, and partner company logos

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Responsive styling
- **Fonts** - Google Fonts (Inter, Geist Mono)
- **Media** - MP4 videos and PNG images

## Setup & Usage

1. Open `index.html` in a web browser to view the landing page
2. No build tools or dependencies required - it's a static site

## Customization

- Update content in `index.html` to modify text and structure
- Modify `style.css` to adjust colors, spacing, and layout
- Replace images in `assets/` folder with your own media
