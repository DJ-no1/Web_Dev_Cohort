# Cursor Homepage Clone (High-Fidelity)

An advanced, responsive, and high-fidelity clone of the [Cursor.sh](https://cursor.sh) landing page. This version features a detailed editor mockup and a more refined design system.

## ✨ New in the Redo

- **High-Fidelity Editor Mockup**: A CSS-based representation of the Cursor interface, including:
  - **Sidebar**: Project explorer with active state.
  - **Editor**: Code editor with syntax highlighting for JavaScript/HTML.
  - **AI Chat Panel**: Integrated chat interface mimicking the "Composer" or "Chat" feature.
- **SVG Brand Assets**: Replaced image-based logos with crisp SVG icons for better scaling and performance.
- **Refined Typography**: Switched to 'Inter' via Google Fonts for a more professional, tech-forward look.
- **Advanced CSS Layouts**: Used CSS Grid and Flexbox to create complex sections like the "Logo Garden" and the dual-column feature cards.
- **Polished Hero Section**: Gradient text and improved call-to-action buttons.

## 🚀 Features

- **Dark Mode Excellence**: A deep, consistent dark theme (`#050505`) with subtle translucent borders.
- **Glassmorphism**: A blurred, sticky navigation header.
- **Responsive Mockup**: The editor mockup adapts to different screen sizes.
- **Interactive States**: Hover effects on all interactive elements.
- **Strictly HTML/CSS**: No JavaScript used, demonstrating the power of modern CSS for complex UI layouts.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Variables, Flexbox, Grid, Backdrop-filters, and Custom Animations.
- **Google Fonts**: Inter.
