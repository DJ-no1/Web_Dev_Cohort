# JavaScript Data Types Assignments

This folder contains assignments to help you understand JavaScript data types.

## Files
- `basic.js`: A simple example with a string variable.
- `assignments.js`: A file with 10 assignments on JavaScript data types.

## How to Run
1. Open a terminal in this folder.
2. Run `node assignments.js` to execute the assignments.
3. Complete each assignment by writing code in the designated sections.
4. Use `console.log()` to output results and check your work.

## Assignments Overview
1. **Primitive Data Types**: Declare variables for each primitive type.
2. **Type Checking**: Use `typeof` to check variable types.
3. **Type Conversion**: Convert between different types.
4. **Arrays**: Work with arrays containing mixed types.
5. **Objects**: Create and manipulate objects.
6. **Null vs Undefined**: Understand the difference.
7. **Special Cases**: Explore type coercion and edge cases.
8. **BigInt**: Work with large integers.
9. **Symbols**: Use symbols as unique identifiers.
10. **Deep Dive**: Handle complex nested structures.

## Troubleshooting
- If `node` is not recognized, install Node.js from https://nodejs.org/.
- Ensure you're in the correct directory: `cd js_assignment/data_types`.
- Check for syntax errors in your code by running the file.
